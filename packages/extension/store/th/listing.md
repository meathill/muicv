## Detailed description
บันทึกประกาศงานจากทุกหน้าเว็บลงบอร์ดงาน Mui Resume ได้ในคลิกเดียว

เจอตำแหน่งงานในหน้ารับสมัครของบริษัท เว็บหางาน โพสต์ของรีครูตเตอร์ หรือโปรไฟล์ X ที่รวมหลายตำแหน่ง? เปิดส่วนขยาย แล้วปล่อยให้ Mui จัดการ:

• อ่านเฉพาะหน้าที่คุณเปิดอยู่ และเฉพาะตอนที่คุณคลิก — ไม่มีสิทธิ์อ่านทุกเว็บไซต์ และไม่ทำงานเบื้องหลัง
• ตรวจหางานอัตโนมัติ: หน้าที่มีข้อมูล JobPosting และหน้า Greenhouse / Lever / Ashby ระบุได้ทันที หน้าอื่นใช้ AI วิเคราะห์ แม้มีหลายตำแหน่งในหน้าเดียว
• ดึงชื่อตำแหน่ง บริษัท สถานที่ และข้อจำกัดด้านพื้นที่ (ประเทศ ภูมิภาค เขตเวลา) ให้รู้ก่อนว่าสมัครได้หรือไม่
• บันทึกได้ 2 แบบ:
  – บอร์ดสาธารณะ (ค่าเริ่มต้น): เพิ่มงานเข้า muicv.com/jobs ฟรีเมื่อพบงาน แม้ซ้ำ และงานใหม่ได้รางวัลเป็นโทเค็น
  – ส่วนตัว: เก็บในบัญชีของคุณเท่านั้น คิดตามการใช้ AI จริง หน้าแบบโครงสร้างหรือ ATS มักเป็น 0
• แจ้งค่าใช้จ่ายก่อนส่ง: แสดงวงเงินกันสูงสุด และคืนส่วนที่ไม่ได้ใช้
• หน้าที่ยาวจะประมวลผลเบื้องหลัง ปิดหน้าต่างแล้วเปิดใหม่ภายหลังเพื่อดูผล

ต้องมีบัญชี muicv.com และ API key (สร้างได้ในแดชบอร์ด)
