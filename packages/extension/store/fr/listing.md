## Name
Mui CV – Enregistreur d'offres

## Short description (122/132)
Enregistrez les offres d'emploi de toute page dans Mui CV. Public gratuit si une offre est trouvée ; privé pour vous seul.

## Detailed description
Enregistrez en un clic les offres d'emploi de n'importe quelle page dans votre tableau Mui CV.

Page carrière, site d'emploi, publication d'un recruteur ou profil X listant plusieurs postes ? Ouvrez l'extension, Mui CV s'occupe du reste :

• Ne lit que la page ouverte, et seulement quand vous cliquez — aucune permission « tous les sites », rien en arrière-plan.
• Détecte automatiquement les offres : données structurées JobPosting et pages Greenhouse / Lever / Ashby reconnues instantanément ; les autres pages sont analysées par IA, même avec plusieurs offres.
• Extrait l'intitulé, l'entreprise, le lieu et les restrictions géographiques (pays, régions, fuseaux horaires) pour savoir si vous pouvez postuler.
• Deux façons d'enregistrer :
  – Pool public (par défaut) : l'offre rejoint le tableau partagé muicv.com/jobs. Gratuit dès qu'une offre est trouvée, même en doublon, avec des jetons en récompense pour les nouvelles offres.
  – Privé : uniquement dans votre compte. Facturé selon l'usage IA réel, généralement 0 pour les pages structurées ou ATS.
• Tarif clair avant l'envoi : le montant maximal réservé est affiché et le reste est remboursé.
• Les pages longues sont traitées en arrière-plan : fermez la fenêtre et rouvrez-la plus tard pour voir le résultat.

Nécessite un compte muicv.com et une clé API (à créer dans votre tableau de bord).
