Mui简历 · 岗位收藏

## Short description (49/132)
把任意网页上的招聘信息提交到 Mui简历岗位库：公共岗位池识别到岗位即免费，私藏只有你自己看得到。

## Detailed description
一键把任意网页上的招聘信息收进 Mui简历岗位库。

在公司招聘页、招聘网站、招聘者的帖子，或者一次列了好几个岗位的 X 账号主页上看到机会？点开扩展，剩下的交给 Mui简历：

• 只读取你当前所在的页面，而且只在你点击时读取——没有「读取所有网站」权限，也不在后台运行。
• 自动识别岗位：带 JobPosting 结构化数据的页面和 Greenhouse / Lever / Ashby 岗位页即时识别；其它页面交给 AI 判断，一页多个岗位也能识别。
• 提取职位、公司、地点和地域限制——仅限哪些国家、地区、时区——投之前就知道自己能不能投。
• 两种收藏方式：
  – 公共岗位池（默认）：岗位进入 muicv.com/jobs 公共岗位库。只要识别到岗位就免费（重复也不扣），有新岗位入库还有 token 奖励。
  – 私藏：只保存在你自己的账号里。按实际 AI 用量扣费；结构化页面或 ATS 岗位页通常为 0。
• 提交前就能看到计费规则和最多预扣多少，用不完的全额退回。
• 内容较多的页面在后台排队处理——可以先关掉弹窗，稍后再打开看结果。

需要 muicv.com 账号和 API key（在控制台生成）。
