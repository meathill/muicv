Mui履歴書 – 求人保存

## Short description (59/132)

## Detailed description
どのウェブページの求人情報も、ワンクリックで Mui履歴書の求人ボードに保存できます。

企業の採用ページ、求人サイト、リクルーターの投稿、複数の求人を載せた X のプロフィール——拡張機能を開くだけで Mui履歴書が処理します。

• 読み取るのは今開いているページだけ、しかもクリックしたときだけ。「すべてのサイトの読み取り」権限はなく、バックグラウンドでも動きません。
• 求人を自動検出：JobPosting 構造化データや Greenhouse / Lever / Ashby のページは即時に認識。その他のページは AI が判定し、1 ページに複数の求人があっても対応します。
• 職種・会社・勤務地・地域制限（対象の国・地域・タイムゾーン）を抽出し、応募できるかを事前に確認できます。
• 保存方法は 2 つ：
  – 公開プール（既定）：muicv.com/jobs の共有求人ボードに追加。求人が見つかれば重複でも無料、新規求人にはトークン報酬。
  – プライベート：自分のアカウントだけに保存。実際の AI 使用量で課金（構造化・ATS ページは通常 0）。
• 送信前に料金ルールと最大仮押さえ額を表示し、未使用分は返金。
• 長いページはバックグラウンドで処理。ポップアップを閉じて後で開けば結果を確認できます。

muicv.com のアカウントと API キー（ダッシュボードで作成）が必要です。
